# The One-Line Exit

One line, at most 140 characters: a funny one-line resignation letter.

`main.ts` writes exactly this line to `/output/entry.txt` (137 characters, no
trailing newline):

> I hereby resign, effective immediately — the office plant I was asked to water has outlived two managers and now technically outranks me.

Run with Node 22: `node main.ts`. No arguments, no input, no network —
deterministic, standard library only.
